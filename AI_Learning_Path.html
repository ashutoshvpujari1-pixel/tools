Turn learning into portfolio projects

Try one small project after each stage. Publish your code, explain what you learned, and keep improving it.

1. AI Study AssistantUse an LLM API to answer questions about a topic and explain answers simply.
2. ML Prediction AppTrain a small model on a public dataset, evaluate it and expose a prediction endpoint.
3. Document Q&A (RAG)Load sample documents, retrieve relevant passages and answer with source references.
4. Java AI Chat APICreate a Spring Boot REST endpoint that calls an AI model and returns the response.
5. Tool-Using AI AgentBuild a constrained agent that calls a safe calculator or a search function.
6. AI App EvaluationCreate test questions, score answer quality, and document limitations and failure cases.

Suggested weekly study routine

📖 Learn — 2 sessions

Study one concept and take short notes in your own words.

💻 Practise — 2 sessions

Run the examples, change inputs, and explain the results.

🚀 Build — 1 session

Make a small improvement to your project and record what you learned.

Tip: consistency matters more than rushing through many courses. You do not need to master every topic before building your first useful AI application.
