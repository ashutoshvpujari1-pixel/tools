📂 How to Integrate into Your Spring Boot Project

  • Java Class: Place the generated Java file under your source folder inside a controller package, for example:
    src/main/java/com/example/demo/controller/<ClassName>.java
  • HTML File: Place the HTML file inside the Thymeleaf templates directory:
    src/main/resources/templates/<viewName>.html
    OR
    src/main/resources/static/<viewName>.html

⚙️ Log4j Setup & Configuration Note

Spring Boot uses Logback by default via spring-boot-starter-logging. To use Log4j2:

  1. Exclude default logging and add the Log4j2 starter in your pom.xml (Maven): 
    <dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
    <exclusions>
        <exclusion>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-logging</artifactId>
        </exclusion>
    </exclusions>
</dependency>
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-log4j2</artifactId>
</dependency>
  2. Optionally, configure log levels or appenders by placing a log4j2.xml or log4j2.spring.xml configuration file inside your src/main/resources/ folder.
