Logging configuration
When selected, the generator adds Log4j2 API/Core dependencies, a log4j2.xml configuration file, and DEBUG-level logging statements in the main class. The XML uses the example absolute log path C:/JavaLogs/application.log. Change this path to a folder writable on your computer before running the project.
