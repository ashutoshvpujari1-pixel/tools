Log4j2 Setup / Configuration

This generated class uses Log4j2 through:

  • org.apache.logging.log4j.Logger
  • org.apache.logging.log4j.LogManager

For Maven-based Spring Boot applications, ensure that Log4j2 dependencies are available. If you are replacing Spring Boot's default Logback implementation, exclude spring-boot-starter-logging and add spring-boot-starter-log4j2.

A typical Spring Boot configuration can be placed in src/main/resources/log4j2-spring.xml.

Example Maven dependency: 

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-log4j2</artifactId>
</dependency>

The generated class contains both logger.debug() and System.out.println() messages so that initialization can be observed through both logging and console output.
